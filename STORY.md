# Case File 8: The Ferryman

Every case file before this one was a room in the same house. This is
the last one — the system Priya Okonkwo-Reyes was investigating the
night her access was revoked for good.

Her notes, scattered across seven other case files, all point here: a
tracking portal nobody secured properly, a waystation relay behind it
that nobody thought anyone would reach, and a vault behind *that* which
nobody thought anyone would reach either. She was wrong about all three
— that's how she got as far as she did.

The Ferryman itself — the shell-company network she'd been chasing —
left one file behind: `dossier.enc`. She never got to open it. Three
things, found in three different places, open it together.

There's no note waiting for you this time. You're the one writing the
last one.
